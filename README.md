# Hogwarts Data Visualizer

This is a Streamlit web app that allows users to explore Hogwarts student data, visualize relationships between features, and optionally students by house.

## Features

- Upload a CSV file
- Select features for scatter plots
- Automatically color points by Hogwarts House
- Show predictions using a simple ML model

## How to Run

1. Clone the repo:
    git clone https://github.com/SunhyeaSakong/hogwarts-streamlit-app.git
    cd hogwarts-streamlit-app

2. Install dependencies:
    pip install -r requirements.txt

3. Start the app:
    streamlit run app.py
    ## Sample data
        You can try the app using the example file in `dataset_train.csv`.
